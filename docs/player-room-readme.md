# osu! 比赛房间选手说明

这份说明给已经进入 mp 房间的参赛选手看。房间由 AI 裁判 Agent 协助管理；必要时会有人类裁判接管。

## 你需要做什么

1. 比赛开始前，请按裁判或房间邀请进入指定 mp 房间。
2. 确认队伍、slot、地图、mod、房间设置都正确。
3. 当你认为自己已经准备好时，在房间聊天发送：

```text
!ref ready
```

4. 如果你需要暂停或有紧急情况，先发送：

```text
!ref pause
```

然后用普通聊天说明原因，等待裁判处理。

## AI 裁判会识别什么

AI 裁判只处理两类信息：

- BanchoBot / SYSTEM 这类系统消息
- 选手以 `!ref` 开头的命令

普通聊天不会触发 AI 自动判断，也不会被 AI 自动回复。比如直接发送 `ready`、`r`、`pause`、`please wait` 不会触发自动裁判动作。

## 当前可用命令

通用：

| 命令 | 作用 |
|------|------|
| `!ref ready` | 告诉 AI 你准备好了；AI 会执行 `!mp settings` 检查房间配置 |
| `!ref pause` | 请求暂停（每人 2 次、每次 120s，仅 ban/pick 或准备阶段） |
| `!ref ?` | 查当前状态（轮到谁 / 比分 / 已 ban / TB 是否解锁），随时可用 |
| `!ref ask <问题>` | 问 AI 助理（如「还能 ban 几张」「TB 啥时候能选」），需裁判端配了 AI |

Best-of（ban/pick）赛中额外用到：

| 命令 | 作用 |
|------|------|
| `!roll` | 裁判提示后双方各 roll 一次，定 ban/pick 先后手 |
| `!ref pick first`/`last`、`!ref ban first`/`last` | roll 后选自己在某一环节的先后手 |
| `!ref pick <编号>` | 轮到你时选图，编号如 `NM1` / `HD2` / `DT3` / `TB` |
| `!ref ban <编号>` | 轮到你时 ban 图（不能 ban TB） |
| `!ref ban skip` | 放弃本次 ban |
| `!ref ff` | 投降（对手赢下整场） |
| `!ref abort` | 开图 30 秒内、遇突发可中止当前图重开 |

> 表述要清晰：`NM1 pick`、`ban HD2` 这类；别写「牛魔4 / NM114514 / DT#」。
> 轮到你才有效；选了不存在 / 已被 ban / 已打过的图，AI 会提示你重选。

## 默认时间规则

如果本场比赛规则书没有特别说明，房间默认使用：

| 项目 | 默认值 |
|------|--------|
| 上人 / 入房 timer | 120 秒 |
| BP timer | 90 秒 |
| 开赛倒计时 | `!mp start 7` |

`!ref ready` 不会直接开赛。它只会让 AI 检查房间设置。

AI 会在以下情况之一满足后开赛：

- BanchoBot / SYSTEM 显示所有玩家都已 ready
- 上人 timer 结束，并且没有选手发送过 `!ref pause`

## 暂停和争议

以下情况请立刻发送 `!ref pause`：

- 选手掉线、网络异常、无法进房
- 房间 slot、队伍、mod、地图设置错误
- 对重赛、弃权、迟到、处罚有争议
- 需要人工裁判确认的特殊情况

所有会影响比赛结果的决定，例如重赛、弃权、处罚、比分修正，都必须由人工裁判确认。AI 不会自行做这类最终判罚。

## 房间内注意事项

- 不要刷屏 `!ref ready` 或 `!ref pause`。
- 不要随意发送 `!mp` 管理命令，除非裁判要求。
- 如果人类裁判在房间内发出指示，以人类裁判为准。
- 如果 AI 裁判没有反应，请等待人类裁判处理，不要重复开局或自行改房间。
- 比赛规则书优先于本说明；本说明只解释默认房间流程和 AI 命令。

## 快速版

```text
准备好了：!ref ready
需要暂停：!ref pause
只识别 !ref 开头的玩家命令
!ref ready 只检查 !mp settings，不会直接开赛
默认上人 120s，BP 90s，开赛 !mp start 7
争议、重赛、弃权、处罚都等人工裁判确认
```
